# homebrew-motas

Homebrew tap for [Motas](https://github.com/dinhkarate/Motas) — a macOS menu bar app that shows AI subscription quota held by your CLIProxyAPI and 9Router proxies.

```bash
brew install --cask --no-quarantine dinhkarate/motas/motas
```

Motas is ad-hoc signed (not notarized), hence `--no-quarantine`. Apple Silicon, macOS 14+.
